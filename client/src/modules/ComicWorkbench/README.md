# 漫画工作台（ComicWorkbench）

纯客户端 AI 漫画生成模块：从小说原文或一句灵感出发，完成「导入 → 分镜 → 角色场景 → 台词 → 描述词 → 生成 → 导出 → 运营文案」的完整漫画制作流程。无后端服务，所有业务逻辑、AI 调用与数据存储都在浏览器本地完成（IndexedDB）。

## 挂载方式

模块通过左侧菜单「漫画工作台」入口挂载，页面组件为 `pages/ComicWorkbenchPage.tsx`。接入方只需在应用路由/菜单中引用该页面组件，模块内部自带路由状态（zustand store）与数据层，不依赖外部业务代码。

## 制作流程（8 步）

1. **项目管理与导入**：新建项目；三种导入方式——导入 TXT 文件、粘贴小说（不经过大模型）、灵感扩写（一句话梗概经 LLM 生成人物/场景/正文，可选叙事模板）。
2. **形态画风**：7 种漫画形态（画幅/分格/台词样式）+ 画风预设与微调 + 试画；发布平台选择（推荐形态联动）。
3. **智能分镜**：确定性分镜算法（5 档密度 + 动态密度 + 高潮加密），手动拆/合/删/增/排序；可选 AI 元数据增强（镜头/情绪/动作概述）。
4. **角色场景**：LLM 从原文提取角色卡与场景卡，上传参考图、合并去重、编辑描述词片段。
5. **台词**：确定性台词提取（引号扫描 + 提示语归属），气泡/字幕/聊天框样式随形态适配，支持手动编辑与拖拽定位。
6. **描述词**：按公式（8 段）组装文生图描述词，支持单镜分段编辑、批量重建、个人模板保存。
7. **生成**：草稿/高清两档批量出图，断点续传、失败自动重试（上限 3 次）、单镜重绘。
8. **导出**：单张 PNG / 条漫长图（台词可合成）/ ZIP 打包；爆款运营文案（按平台生成标题/摘要/正文/话题标签）。

## 目录结构

```
ComicWorkbench/
├── pages/            # 页面入口（ComicWorkbenchPage）
├── components/       # 步骤面板（steps/）、通用组件（common/）、设置（settings/）
├── services/         # 业务服务层（AI 调用、分镜、台词、描述词、生成队列、导出、同步）
│   ├── ai/           # LLM/生图客户端与配置
│   ├── import/       # 内容导入（含灵感扩写）
│   ├── storyboard/   # 分镜算法与元数据
│   ├── cast/         # 角色场景卡
│   └── export/       # 条漫渲染与 ZIP 打包
├── hooks/            # react-query 查询钩子（comicKeys 集中管理）
├── stores/           # zustand 状态（当前项目/章节/步骤）
├── db/               # IndexedDB 数据层（键空间见 types 的 ComicDbKeys）
├── config/           # 全部可配置项 JSON（见下）
└── types/            # 全部 TypeScript 类型定义
```

## config 配置指南

所有可配置项独立存放在 `config/*.json`，禁止硬编码到业务逻辑：

| 文件 | 内容 |
| --- | --- |
| `comicForms.json` | 漫画形态：画幅、分格数、台词模式、描述词前缀、预览样式 |
| `stylePresets.json` | 画风预设：关键词、负向词、色调/线条/画质/光影 |
| `shotDensity.json` | 分镜密度：5 档阈值、拆分规则、动态密度关键词 |
| `promptFormula.json` | 描述词公式：8 段顺序、段模板、镜头/台词呈现/画质词典 |
| `narrativeTemplates.json` | 爆款增强：4 个叙事模板（注入灵感扩写与元数据增强）、3 个发布平台（推荐形态 + 节奏提示） |
| `aiProviders.json` | AI 供应商目录与超时/重试/并发默认值 |
| `sensitiveWords.json` | 敏感词表（warn 行为） |

修改 JSON 后刷新页面即可生效；格式错误会在控制台给出带文件名与位置的提示，不会白屏。

## 关键设计约束

- **原文零修改**：章节正文导入后只读，分镜/台词仅用 `startIndex/endIndex` 字符索引引用原文，绝不改写。
- **数据流单向**：「原文 → 分镜 → 角色/场景 → 描述词 → 图片」。上游修改后下游只标记待更新（stale），绝不静默级联改写。
- **版本链 stale 判定**：每个阶段产出时在面板上盖章当时的章节版本快照（`dialogueBasis`/`promptBasis`/`imageBasis`）；步骤页横幅展示待更新数量，「一键同步」按依赖序重跑文本链（台词重提 → 描述词重建），画面重生成消耗生图额度、由用户在生成步骤显式触发。
- **AI 调用规范**：全部走 `services/ai/`，API Key 只存本机，内置超时/重试/JSON 修复/错误兜底。
- **长文本性能**：分镜编辑器、原文预览使用 `@tanstack/react-virtual` 虚拟滚动。

详细架构决策见 `docs/wiki/architecture/comic-workbench-module-boundary.md`。
